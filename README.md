## hdzero-tooling

STEP (aka ISO 10303) files (that can be imported in most CAD softwares) for:

* AIO15
* Freestyle V2 VTX Antenna
* HDZero Freestyle V2 VTX
* HDZero Monitor Shell
* HDZero VRX Shell
* HDZero Box Pro
* HDZero Goggle 20220909
* HDZero Goggle 2 20260801
* HDZero Eco Camera
* HDZero LUX Camera
* HDZero Micro V2
* HDZero Nano 90
* HDZero Nano 90 Frame 14to19
* HDZero Nano V2
* HDZero Nano V3
* HDZero Nano Lite

Production information: https://www.hd-zero.com/
